## New scripts
| script | what | tested |
|---|---|---|
| `evaluate_rq3.py` (+ `.slurm`) | scores all arms on the 128 test tiles: the paper's P-ruler fingerprint **and** absolute reflectance PSNR/SSIM/MAE; bootstrap CIs, paired differences vs a reference arm (Wilcoxon), figure | 4 test tiles, old WaveCM output as a stand-in arm |
| `prepare_real.py` | the paper's 3,000 real Sentinel-2 fingerprints + their fake-LR rows as θ=0 context; flags tiles whose AOI fed the NPE simulations | yes: 2,372 tiles / 111 groups held out |
| `ppc.py` | posterior predictive check: re-simulate each real tile at posterior draws, locate the real fingerprint | runs; 4 tiles only |
| `build_arm2.py` | arm-2 tiles: θ from real-S2 posteriors (pool or matched), φ random, optional per-band gain/offset from the same real pair | θ=0 reproduces rq3 fake-LR exactly; `--radiometry pair` matches S2 band means |
| `npe.py apply --samples-out` | saves posterior samples per tile (for arm 2 and PPC) | yes |
| `simulate.py --real` | fingerprints the real S2 pair of each RQ3 tile (for `--source matched`) | yes, consistent with `evaluate_rq3.py` |

## Dev results (structural metrics only, small dev NPE: 3,200 sims, ensemble of 2) — NOT thesis numbers
Posterior medians over 200 held-out real tiles (prior σ_b U[0,4] px, r U[0,3.33] px, σ_n U[0,0.02]):

|            | fake-LR (positive control) | real Sentinel-2 |
|------------|----------------------------|-----------------|
| blur σ_b   | 0.32 px                    | 1.8 px (IQR 1.1–2.2) |
| shift r    | 0.38 px                    | 1.6 px (≈ ½ S2 pixel) |
| noise σ_n  | 0.0006                     | 0.0023 |

The control works: fake-LR lands at the lower edge with narrower intervals. Sentinel-2 posteriors are wide.

## Decisions for you
1. **Arm 2 radiometry.** The NPE can't see per-band gain/offset (the P ruler removes it), but real S2 is
   clearly darker than PS (e.g. NIR mean 0.30 vs 0.38 on one test tile). `--radiometry pair` copies the
   measured gain/offset of the same real pair onto each arm-2 tile; `none` keeps the pure NPE forward model.
   Without it, arm 2 trains on PS-bright inputs but is tested on darker real S2, as arm 1 is.
2. **Arm 2 source.** `pool` = degradations of the real-S2 population (posterior of random real tiles);
   `matched` = each tile degraded like its own S2 pair (needs `simulate.slurm real 1` first).
3. **Evaluation headline.** P-ruler metrics hide brightness errors; absolute metrics include them. On 4 tiles,
   old WaveCM vs plain S2: P-ruler PSNR −0.5 dB, absolute PSNR +12 dB. Report both, and say which answers RQ3.

## Caveats found
- PPC on fake-LR is NOT expected to be uniform (θ=0 is at the prior edge); use held-out simulations as the
  sanity input instead.
- σ_n slightly under-estimated in the dev NPE (SBC KS p = 0.006, n = 150). Recheck with the full run.
